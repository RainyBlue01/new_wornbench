# 表单设计器组件支持事件清单

## 1 文档说明

本文档整理表单设计器中各组件可以开放给前端插件的事件，用于设计器右侧“事件”面板的事件配置。

整理依据：

- 当前启用的组件清单；
- 各组件的实际封装；
- Arco Design Vue 官方组件文档。

本文将事件分为三种状态：

- **当前已接入**：组件封装已经监听该事件，并执行现有的 `inputItem` 或业务处理方法；
- **原生可接入**：底层 Arco 组件已经提供事件，但当前业务组件尚未统一转发给插件执行器；
- **业务自定义**：不是 Arco 原生事件，需要由业务组件在具体操作完成时主动触发。


## 2 组件事件总览

### 2.1 基础组件

| 组件 | 类型 | 底层实现 | 建议开放事件 | 当前封装情况 |
| --- | --- | --- | --- | --- |
| 单行文本 | `INPUT` | Arco Input | 输入值时、值修改时、获取焦点时、失去焦点时、点击清空按钮时、按下回车时 | 依赖 `showItem.vue` 对值的深度监听触发现有输入逻辑，尚未显式转发其他事件 |
| 多行文本 | `TEXTAREA` | Arco Textarea | 输入值时、值修改时、获取焦点时、失去焦点时、点击清空按钮时 | 已监听原生输入事件，但处理函数为空；其他事件尚未转发 |
| 单选框组 | `RADIO` | Arco RadioGroup | 值修改时 | 已监听值修改事件并调用 `inputItem` |
| 多选框组 | `CHECKBOX` | Arco CheckboxGroup | 值修改时 | 依赖值监听，组件内部尚未显式绑定值修改事件 |
| 开关 | `SWITCH` | Arco Switch | 值修改时、获取焦点时、失去焦点时 | 依赖值监听，尚未显式转发 |
| 下拉选择 | `SELECT` | Arco Select | 值修改时、点击清空按钮时、搜索时、展开或收起时、滚动到底部时 | 已监听值修改事件并调用 `inputItem` |
| 多选下拉选择 | `SELECT_MULTIPLE` | Arco Select | 值修改时、点击清空按钮时、移除选项时、搜索时、展开或收起时、滚动到底部时、超过数量限制时 | 已监听值修改事件并调用 `inputItem` |
| 附件 | `ATTACH` | Arco Upload | 文件列表修改时、上传进度变化时、上传成功时、上传失败时、预览文件时、超过数量限制时、删除文件前 | 已接入预览和删除前处理；其余事件尚未转发 |
| 图片 | `PICTURE` | Arco Upload | 文件列表修改时、上传进度变化时、上传成功时、上传失败时、预览图片时、超过数量限制时、删除图片前 | 已接入预览和删除前处理；其余事件尚未转发 |
| 编辑器 | `EDITORS` | 自定义富文本编辑器 | 输入值时、值修改时、获取焦点时、失去焦点时 | 当前只包含展开和收起交互，需由编辑器实例主动转发内容事件 |

### 2.4 布局和展示组件

| 组件 | 类型 | 建议开放事件 | 说明 |
| --- | --- | --- | --- |
| 栅格布局 | `ROW` | 生命周期事件 | 布局组件本身没有业务值，不建议开放输入和值修改事件 |
| 列 | `COL` | 生命周期事件 | 作为内部容器使用，不建议单独展示组件事件面板 |
| 标题 | `TITLE` | 点击时、生命周期事件 | 只有存在点击交互需求时才开放点击事件 |
| 分割线 | `SPLIT_LINE` | 生命周期事件 | 纯展示组件通常不需要业务事件 |

## 3 Arco 原生事件与设计器事件映射

### 3.1 输入类组件

| Arco 原生事件 | 设计器事件 | 事件数据 |
| --- | --- | --- |
| `input` | `component.input` | 当前值和原生输入事件 |
| `change` | `component.change` | 修改后的值和原生事件 |
| `focus` | `component.focus` | 原生焦点事件 |
| `blur` | `component.blur` | 原生焦点事件 |
| `clear` | `component.clear` | 原生点击事件 |
| `pressEnter` | `component.pressEnter` | 原生键盘事件 |

### 3.2 选择类组件

| Arco 原生事件 | 设计器事件 | 事件数据 |
| --- | --- | --- |
| `change` | `component.change` | 当前选中值 |
| `clear` | `component.clear` | 原生点击事件 |
| `remove` | `component.remove` | 被移除的选项 |
| `search` | `component.search` | 当前搜索文字 |
| `popupVisibleChange` | `component.popupVisibleChange` | 下拉面板是否可见 |
| `dropdownReachBottom` | `component.reachBottom` | 下拉区域滚动事件 |

### 3.3 日期和时间类组件

| Arco 原生事件 | 设计器事件 | 事件数据 |

## 4 建议在设计器首期开放的事件

为了避免事件面板一次出现过多低频事件，建议首期按以下范围开放：

1. 所有可编辑字段统一开放“值修改时”。
2. 单行文本、多行文本、数字和金额额外开放“输入值时”“获取焦点时”“失去焦点时”“点击清空按钮时”。
3. 单行文本、电话、身份证号码、邮箱和 URL 额外开放“按下回车时”。
4. 下拉选择和多选下拉选择开放“点击清空按钮时”和“搜索时”；多选组件额外开放“移除选项时”。
5. 日期、日期范围、时间和时间范围开放“选择时”“点击确定时”“点击清空按钮时”。
6. 附件和图片开放“上传成功时”“上传失败时”“预览时”“删除前”。
7. 按钮开放“点击时”，关联查询开放“查询成功时”和“查询失败时”。
8. 所有组件均可配置生命周期，但默认折叠到单独的“生命周期”分组中。
